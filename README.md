# AI Trend · Промпты 🍌

Каталог детальных промптов для AI-игр и **генерации изображений** с персонализацией под ученика и **играбельными демо прямо в браузере**.

🔗 **Демо:** https://blessed07777.github.io/ai-trend-prompts/

Вдохновлено идеей сайта `amra1000.github.io/ai-trend-prompts`, но с упором на качество: подробные промпты, рабочие кнопки и настоящие мини-игры.

## Что внутри

### 🎮 Игры для мальчиков
- **Space Defender** — космический шутер: волны врагов, апгрейды, боссы, комбо.
- **Turbo Racer** — бесконечная гонка: смена полос, нитро, монеты, рекорды.
- **Penalty King** — пенальти: прицел + сила + вратарь-AI.
- **Ninja Run** — раннер: двойной прыжок, подкаты, монеты.
- **Snake Arena** — неоновая змейка с порталами и бонусами.
- **Meteor Catcher** — лови кристаллы, уворачивайся от метеоров, щит.

### 👗 Игры для девочек
- **Style Studio** — подбор образа под бриф клиента, звёзды, показ.
- **My Café** — собирай заказы гостей, чаевые, рейтинг кафе.
- **Pet World** — виртуальный питомец: голод/радость/энергия/чистота, уровни.
- **Memory Match** — парные карточки, уровни, ходы и время.
- **Bubble Pop** — лопай группы пузырей одного цвета на очки.
- **Sweet Catch** — лови сладости, избегай перчинок, sugar-rush.

### 🎨 Генерация фото
Интерактивная лаборатория: выбери **кто** (авокадо, собака, кот, банан, клубника,
брокколи, перчик, робот), **где** (космос, кухня, сцена, город, пляж, джунгли) и **стиль** —
сайт процедурно рисует милого персонажа на canvas (например, «собака в скафандре в космосе»)
и собирает готовый **английский промпт** для генеративных моделей.
Кнопки: сгенерировать, копировать промпт, скачать PNG, поделиться.

## Возможности
- 🧩 **Персонализация** — имя и описание ученика автоматически вставляются во все промпты.
- 📋 **Рабочие кнопки** — копирование промпта, «Поделиться» (Web Share API + fallback), «Играть».
- 🌗 **Светлая и тёмная темы** (сохраняются в localStorage).
- 📱 **Адаптивность** — десктоп (мышь/клавиатура) и мобайл (тач/свайп).
- ⚡ Без зависимостей: чистые HTML, CSS, JS. Игры — на HTML5 Canvas, рекорды в localStorage.

## Технологии
Чистый статический сайт — никаких сборщиков и CDN.

```
index.html
css/styles.css
js/data.js        # каталог промптов + пресеты генерации
js/games.js       # движки 11 играбельных мини-игр
js/imagelab.js    # лаборатория генерации изображений
js/app.js         # вкладки, персонализация, копирование, модалки
```

## Запуск локально
```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```
