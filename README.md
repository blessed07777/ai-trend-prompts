# AI Trend · Промпты 🍌

Каталог детальных промптов для AI-игр и **генерации изображений** с персонализацией под ученика.

🔗 **Демо:** https://blessed07777.github.io/ai-trend-prompts/

Вдохновлено идеей сайта `amra1000.github.io/ai-trend-prompts`, но с упором на качество: подробно прописанные промпты, рабочие кнопки и удобная персонализация.

## Что внутри

### 🎮 Промпты игр для мальчиков
Space Defender (космический шутер), Turbo Racer (бесконечная гонка), Penalty King (пенальти),
Ninja Run (раннер), Snake Arena (неоновая змейка), Meteor Catcher (лови ресурсы).

### 👗 Промпты игр для девочек
Style Studio (свой бренд одежды), My Café (своё кафе), Pet World (виртуальный питомец),
Memory Match (парные карточки), Bubble Pop (лопай пузыри), Sweet Catch (лови сладости).

Каждый промпт — готовая подробная спецификация (цели, механики, управление, UI, арт-стиль,
тех. требования) для генерации игры в один HTML-файл на HTML5 Canvas.

### 🎨 Генерация фото
Интерактивная лаборатория: выбери **кто** (авокадо, собака, кот, банан, клубника,
брокколи, перчик, робот), **где** (космос, кухня, сцена, город, пляж, джунгли) и **стиль** —
сайт процедурно рисует милого персонажа на canvas (например, «собака в скафандре в космосе»)
и собирает готовый **английский промпт** для генеративных моделей.
Кнопки: сгенерировать, копировать промпт, скачать PNG, поделиться.

## Возможности
- 🧩 **Персонализация** — имя и описание ученика автоматически вставляются во все промпты.
- 📋 **Рабочие кнопки** — копирование промпта и «Поделиться» (Web Share API + fallback).
- 🌗 **Светлая и тёмная темы** (сохраняются в localStorage).
- 📱 **Адаптивность** — десктоп и мобайл.
- ⚡ Без зависимостей: чистые HTML, CSS, JS.

## Структура
```
index.html
css/styles.css
js/data.js        # каталог промптов + пресеты генерации
js/imagelab.js    # лаборатория генерации изображений
js/app.js         # вкладки, персонализация, копирование
```

## Запуск локально
```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```
